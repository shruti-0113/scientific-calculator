# Scientific Calculator

A modern, feature-rich calculator web application with scientific functions, matrix operations, and calculation history.

## Features

### Basic Calculator
- Addition, Subtraction, Multiplication, Division
- Parentheses support
- Decimal numbers
- Percentage calculations

### Scientific Calculator
- **Trigonometry:** sin, cos, tan, sin⁻¹, cos⁻¹, tan⁻¹ (degrees)
- **Logarithms:** log (base 10), ln (natural), eˣ
- **Roots:** Square root, Cube root
- **Powers:** x², x³, xⁿ, 10ˣ, 2ˣ
- **Other:** Factorial (x!), Absolute value (|x|), Modulo, Constants (π, e)

### Matrix Operations
- Supports 2×2, 3×3, and 4×4 matrices
- **Addition** (A + B)
- **Subtraction** (A − B)
- **Multiplication** (A × B)
- **Scalar Multiplication** (k × A)
- **Transpose** (Aᵀ)
- **Determinant** (det A)
- **Inverse** (A⁻¹)
- **Trace** (tr A)

### Calculation History
- Automatically saves every calculation
- Stored in localStorage (persists across sessions)
- Click any past result to load it back
- Delete individual items or clear all history
- Stores up to 50 entries

### Keyboard Support
| Key | Action |
|-----|--------|
| 0-9 | Insert number |
| + - * / | Operators |
| ( ) | Parentheses |
| ^ | Power |
| % | Percentage |
| Enter / = | Calculate |
| Backspace | Delete last |
| Escape | Clear all |

### UI & Design
- Modern dark theme with gradient background
- Distinct color-coded buttons for each operator
- Responsive design for mobile and desktop
- Smooth animations and hover effects
- Three modes: Basic, Scientific, Matrix
- Slide-out history sidebar

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (no dependencies)

Open `index.html` in your browser to use the calculator.
